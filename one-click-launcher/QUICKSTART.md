## 📋 开始之前

### 您需要什么？

**必需品：**
- 一台电脑（Windows 10/11、macOS 或 Linux）
- 稳定的网络连接
- 管理员权限（仅首次安装需要）

**系统要求：**
- 内存：至少 4GB（推荐 8GB+）
- 磁盘空间：至少 2GB 可用空间
- 网络：宽带连接

## 🚀 三步快速启动

### 第1步：获取软件

#### 方法一：下载压缩包（推荐新手）

1. 访问项目官网：https://quant-trading.example.com
2. 点击"下载最新版本"
3. 选择适合您操作系统的版本：
   - Windows用户：下载 `trading-platform-windows.zip`
   - Mac用户：下载 `trading-platform-mac.zip`
   - Linux用户：下载 `trading-platform-linux.tar.gz`

#### 方法二：使用Git（适合稍有经验的用户）

```bash
# 国内用户
git clone https://gitee.com/lion20231226/quantitative-trading-platform.git

# 国外用户
git clone https://github.com/lion231226/quantitative-trading-platform.git
```

### 第2步：启动平台

#### Windows 用户

1. **双击启动器**
   - 进入项目文件夹
   - 双击 `start-windows.bat` 文件
   - 出现黑色窗口，显示启动进度

2. **等待安装完成**
   - 首次运行需要下载依赖（约2-5分钟）
   - 看到"启动完成"提示即为成功

#### Mac 用户

1. **打开终端**
   - 按 `Command + 空格键`
   - 输入"终端"并打开

2. **运行启动命令**
   ```bash
   cd 下载/quantitative-trading-platform/one-click-launcher
   chmod +x launcher.py
   python3 launcher.py
   ```

3. **输入密码**
   - 如果提示输入密码，请输入您的电脑登录密码

#### Linux 用户

1. **打开终端**
   - 按 `Ctrl + Alt + T`

2. **运行启动命令**
   ```bash
   cd ~/Downloads/quantitative-trading-platform/one-click-launcher
   chmod +x launcher.py
   python3 launcher.py
   ```

### 第3步：开始使用

启动成功后，浏览器会自动打开平台首页：

- **平台地址**：http://localhost:3000
- **如果浏览器未自动打开**：手动访问 http://localhost:3000

🎉 **恭喜！您可以开始使用量化交易平台了！**

## 🔧 常见操作

### 创建您的第一个策略

1. **进入策略分析页面**
   - 点击顶部导航的"策略分析"

2. **选择基础策略**
   - 选择"单均线策略"（最适合新手）
   - 点击"开始分析"

3. **调整参数**
   - **均线周期**：设置移动平均线天数（建议20天）
   - **初始资金**：设置虚拟投资金额
   - **止损比例**：设置最大可接受亏损

4. **运行回测**
   - 点击"运行回测"
   - 等待计算完成（通常几秒钟）

5. **查看结果**
   - **收益曲线**：查看策略历史表现
   - **关键指标**：年化收益、最大回撤等
   - **交易记录**：查看每笔交易详情

### 设置风险控制

1. **进入设置页面**
   - 点击右上角用户菜单
   - 选择"风险管理"

2. **配置止损**
   - **单笔止损**：每笔交易最大亏损比例
   - **日止损**：单日最大亏损金额
   - **总止损**：整体账户最大亏损比例

3. **保存设置**
   - 点击"保存配置"
   - 系统将自动应用新的风险控制

### 导出分析报告

1. **选择报告内容**
   - 选择要导出的时间范围
   - 选择包含的分析指标

2. **选择导出格式**
   - Excel表格：适合数据分析
   - PDF报告：适合分享和打印
   - 图片格式：适合插入文档

3. **下载报告**
   - 点击"导出"按钮
   - 选择保存位置

## 🆘 遇到问题？

### 常见问题快速解决

#### 问题1：启动失败

**现象**：双击启动器后出现错误信息

**解决方案**：
1. 确保有管理员权限
2. 检查网络连接
3. 关闭杀毒软件重试

#### 问题2：浏览器无法打开

**现象**：启动成功但浏览器没反应

**解决方案**：
1. 手动打开浏览器
2. 访问：http://localhost:3000
3. 如果仍无法访问，重启启动器

#### 问题3：页面加载缓慢

**现象**：平台页面打开很慢或卡顿

**解决方案**：
1. 检查网络连接速度
2. 关闭其他占用网络的程序
3. 刷新浏览器页面

#### 问题4：数据更新不及时

**现象**：市场数据不是最新的

**解决方案**：
1. 检查网络连接
2. 点击页面上的"刷新"按钮
3. 等待几秒钟后重试
