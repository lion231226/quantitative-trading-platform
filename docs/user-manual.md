## 📚 **策略教程**

### **单均线策略原理**

#### **什么是移动平均线？**

移动平均线（Moving Average, MA）是最基础的技术分析指标，计算方法：

```
MA(n) = (P1 + P2 + ... + Pn) / n
```

其中：
- `MA(n)`: n日移动平均线
- `P1, P2, ..., Pn`: 最近n天的收盘价
- `n`: 均线周期

#### **交易信号生成**

**买入信号（金叉）**:
- 当价格从下方突破移动平均线时
- 表示上涨趋势可能开始

**卖出信号（死叉）**:
- 当价格从下方跌破移动平均线时
- 表示下跌趋势可能开始

#### **策略优势**

- **简单易懂** - 只需要一个参数（均线周期）
- **趋势跟踪** - 能够捕捉中长期趋势
- **减少噪音** - 过滤短期价格波动
- **适用性广** - 适用于各种市场和时间周期

#### **策略局限**

- **滞后性** - 信号生成晚于价格变化
- **震荡市场失效** - 在横盘市场中频繁产生错误信号
- **参数敏感** - 不同周期对结果影响很大
- **单一指标** - 仅基于价格，忽略成交量等其他信息

### **参数选择指南**

#### **均线周期选择**

| 周期范围 | 适用场景 | 特点 |
|---------|---------|------|
| 5-10日 | 短线交易 | 反应灵敏，信号频繁 |
| 15-25日 | 中线交易 | 平衡灵敏度和稳定性 |
| 30-60日 | 长线交易 | 信号稳定，滞后性明显 |

#### **建议参数**

- **初学者**: 20日均线（平衡效果）
- **短线交易**: 10日均线（灵敏度高）
- **长线投资**: 30日均线（稳定性好）

## 📊 **数据分析指南**

### **关键绩效指标解读**

#### **收益指标**
- **总收益率**: 策略期间的累计收益百分比
- **年化收益率**: 转换为年度的收益率，便于比较
- **最大回撤**: 历史最大亏损幅度，衡量风险
- **夏普比率**: 风险调整后收益，>1为优秀

#### **风险指标**
- **波动率**: 收益率的标准差，衡量波动程度
- **胜率**: 盈利交易占总交易的比例
- **盈亏比**: 平均盈利与平均亏损的比值
- **最大连续亏损**: 最长的亏损交易次数

### **结果分析建议**

#### **🟢 优秀策略特征**
- 年化收益率 > 15%
- 最大回撤 < 20%
- 夏普比率 > 1.0
- 胜率 > 50%

#### **🟡 需要改进**
- 最大回撤 > 30%
- 夏普比率 < 0.5
- 胜率 < 40%

#### **🔴 建议放弃**
- 总收益为负
- 最大回撤 > 50%
- 交易次数过少（< 10次）

## ❓ **常见问题**

### **基础问题**

**Q: 我没有任何金融知识，能使用这个平台吗？**
A: 完全可以！平台专为初学者设计，提供完整的教程和指导。

**Q: 策略回测结果能保证未来收益吗？**
A: 不能。历史回测仅供参考，实际交易存在风险，请谨慎投资。

**Q: 为什么有些品种没有数据？**
A: 可能是品种代码不正确或数据源暂时不可用，请尝试其他品种。

### **技术问题**

**Q: 页面加载很慢怎么办？**
A: 建议使用Chrome浏览器，检查网络连接，或刷新页面重试。

**Q: 策略计算失败怎么处理？**
A: 检查参数设置是否合理，特别是时间范围不要过长或过短。

**Q: 移动端体验如何优化？**
A: 建议横屏使用，或使用平板设备获得更好的体验。

### **数据分析问题**

**Q: 为什么我的策略收益率为负？**
A: 单均线策略在震荡市场中表现不佳，建议尝试不同参数或品种。

**Q: 夏普比率是什么意思？**
A: 夏普比率衡量风险调整后收益，>1表示每承担1单位风险获得>1单位收益。

**Q: 如何选择最优参数？**
A: 没有绝对的最优参数，建议根据交易风格选择：短线用小周期，长线用大周期。
